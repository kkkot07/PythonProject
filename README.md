# PythonProject

## Описание проекта

Проект предназначен для работы с данными о банковских операциях клиента. 
Реализованы функции обработки списка операций:
- `filter_by_state` — фильтрация по статусу выполнения;
- `sort_by_date` — сортировка по дате операций.
